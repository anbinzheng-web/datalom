# 决策：数据集存储与导出

状态：已接受

规范化数据集使用 Parquet 作为主存储，采集原始响应使用压缩 JSONL 归档，SQLite 或 PostgreSQL 只保存控制面元数据。JSON、JSONL、CSV、SQLite 和大模型训练格式均作为异步导出产物生成，不作为采集器的内部写入格式。

数据集版本不可变。采集器先写临时对象，完成清洗、去重、分区、schema 校验和校验和计算后，通过 manifest 发布版本。已发布版本不允许原地修改。

控制面通过 `ObjectStore` 抽象访问数据文件：单机 Docker 使用本地卷，多节点部署使用 S3 或 MinIO。导出任务独立于用户 API 的请求连接池和并发额度，避免大文件生成拖慢在线请求。
