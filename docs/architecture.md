# 架构专题与文档索引

架构总览、目录职责、依赖方向和开发约定统一维护在 [AGENTS.md](../AGENTS.md)。本目录用于按需深入了解具体设计，也可以收录有长期维护价值的其他专题。

| 专题 | 阅读时机 |
| --- | --- |
| [接口、运行时与本机数据](runtime.md) | 修改 API 生成链路、会话、网络、构建或路径 |
| [数据集存储与导出决策](data-storage.md) | 实现批量采集、数据集发布或导出；这是设计方向，非完成声明 |

平台逆向经验随代码放在 `packages/platform-*/research/README.md`，应用局部约定放在各应用 README。新增专题应有具体读者和用途，不为每次改动创建文档，也不复制 AGENTS.md 的架构总览。
