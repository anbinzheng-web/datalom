# 数据集存储与导出决策

状态：已接受的设计方向；具体落地以代码为准。

- 原始响应以压缩 JSONL 归档；清洗、去重后的规范化数据使用 Parquet。
- PostgreSQL保存控制面元数据，不承载大文件交付。JSON、JSONL、CSV、SQLite 和训练格式由异步导出生成。
- 数据集版本不可变。先写临时对象，完成 schema、分区和校验和检查，再发布 manifest；禁止原地修改已发布版本。
- 控制面通过 ObjectStore 访问文件：单机使用持久卷，多节点可用 S3/MinIO。数据桶不写入镜像，在线数据库文件不作为下载副本。
- 批量采集和导出由独立执行单元承载，不占用在线 API 的连接池及额度。优先调用共享平台实现；必须经 API 时使用独立内部资源配额。
- 下载使用流式传输，支持版本、校验和及断点续传；不在请求进程中现场转换 GB 级数据。
